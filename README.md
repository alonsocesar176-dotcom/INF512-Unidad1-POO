# INF512-Unidad1-POO
Lo que hice fue armar una clase sencilla en C# que representa un producto. Le di atributos privados como nombre, precio y cantidad, y un constructor para inicializarlos. Luego agregue métodos que permiten mostrar la información del producto en consola, aumentar la cantidad validando que sea positiva y cambiar el precio asegurando que no sea cero o negativo. En resumen, es una estructura básica para manejar productos en un inventario con operaciones simples de consulta y actualización.
